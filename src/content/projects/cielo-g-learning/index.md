## Overview  
The **CIELO-G Learning App** is an interactive platform developed to make Earth science education more engaging through game-based lessons. It serves as the main hub for showcasing and hosting all courses created with my **CIELO-G Learning Framework**.

🌐 [Visit the CIELO-G Learning App](https://cielo-g.github.io/courses/)

[![Visit the CIELO-G Learning App](https://raw.githubusercontent.com/CIELO-G/cielo-g.github.io/refs/heads/main/public/social-card.png)](https://cielo-g.github.io/courses/)  

## Background  
Developed and launched as part of an **NSF-funded project**, the web-app goal is to provide teachers and students with an easy, professional way to access and play educational courses.  

## Development  
The platform integrates lessons, visuals, and progress systems into a single site.

## Features  
- Centralized access to all CIELO-G learning courses  
- Clean, professional website design for easy navigation  
- Browser-based play with no installation required  
- Integrated video, text, and interactive content  

## Results  
Successfully launched as the official **CIELO-G Learning App**, used to showcase interactive Earth science lessons.  

## Tech Stack  
Godot 4 · GDScript · CSS · TypeScript · Astro · Canva
