## Overview  
A 3D voxel character demo made in **Unreal Engine 5**, with third-person movement, animations, and physics-based puzzles.

## Background  
Created to explore voxel-style visuals, animation, and interaction.

## Development  
Built with Unreal’s **Blueprint system**, using a **state machine** for character logic and animation. Integrated **physics body interactions** for grabbing and dropping objects, and connected these systems to simple puzzle elements.  

## Features  
- Third-person voxel character with state-driven animations  
- Physics-based grab and drop system  
- Interactive objects and puzzles  
- Stylized voxel environment  

## Results  
The demo runs smoothly and highlights how voxel visuals and simple physics systems can create fun, interactive gameplay.  

## Tech Stack  
Unreal Engine 5 · Blueprints · MagicaVoxel · Mixamo
